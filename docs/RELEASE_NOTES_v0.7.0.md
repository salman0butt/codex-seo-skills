# Codex SEO Skills v0.7.0 — Offline Evidence Reports & Handoff

## New

- `seo_report_builder.py`: combines supplied aggregate GSC/GA4 JSON and public raw-HTML quick-audit JSON into structured JSON or Markdown with **zero network requests**, no credential reads, no OAuth refresh and no site modifications.
- Historical changes only when an operator uses `--confirm-same-property` **after independently checking that redacted historical/current sources are from the same property**, and only for equal-length adjacent nonoverlapping time windows. Changes describe measurements; they **do not prove ranking improvement, business outcomes or cause**.
- GSC click/impression count deltas, CTR percentage-point changes and mean position differences are distinct from GA4 organic sessions, users and engaged sessions. Division-by-zero historical percentages become unavailable, not infinity or zero.
- Reviewed raw-HTML findings become **advisory** prioritized developer tickets with source audit reference, suggested action, acceptance criteria, owner placeholder and verification steps. No action is automatically approved, implemented or deployed.
- Bounded, schema-validated inputs (256 KiB each, up to 10 public page audits), sanitized output with public-page paths, search queries, property identifiers, tokens and untrusted evidence text omitted. Explicit provenance caveat: source JSON shape can be verified but its origin cannot be authenticated.
- Markdown and JSON output, atomically created with owner-only file permissions. Existing outputs require `--overwrite`; sources cannot be replaced; symlink outputs are rejected.
- 18 new offline unit tests for source validation, comparisons, no-data, empty baselines, untrusted text, handoff order and output safety. New clearly labeled **synthetic**, fabricated integration fixtures and expanded CI smoke.

## Verified / unverified

- CI must pass Python 3.11/3.12, macOS managed runtime, Linux Chromium and offline report integration checks on the exact release tag.
- The synthetic sample metrics are **not actual website data**. The builder can process legitimately collected exports but cannot attest that a local file was actually generated by Google. The historical property link is a **human attestation**, not an API proof.
- Real private Search Console and GA4 reporting still requires an authorized user, matching properties and working OAuth access. No private Google property was accessed, no paid SEO provider calls were made, and no live site was modified for this release.

## Run

```bash
git clone --branch v0.7.0 https://github.com/salman0butt/codex-seo-skills.git
cd codex-seo-skills
python3 scripts/install_codex.py
./scripts/codex-seo run seo_report_builder.py \
  --gsc-current examples/synthetic/gsc-current.json \
  --gsc-previous examples/synthetic/gsc-previous.json \
  --ga4-current examples/synthetic/ga4-current.json \
  --ga4-previous examples/synthetic/ga4-previous.json \
  --quick-audit examples/synthetic/quick-audit.json \
  --confirm-same-property --format markdown
```

These example values are **fictional fixtures**. For real reports, use only your authorized exports and consult [the reporting guide](EVIDENCE_REPORTING.md).
